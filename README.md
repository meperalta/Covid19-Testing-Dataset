📊 COVID-19 Testing Data — Exploratory Data Analysis (Excel)

Overview

This project explores COVID-19 testing data from 2021 to uncover patterns across symptoms, demographics, and test results. Using Excel, I performed end-to-end exploratory data analysis — from data cleaning and preprocessing to visualization and dashboard development — to transform raw data into actionable insights.

Business / Analysis Objective

	•	Improve data quality and usability for analysis
	•	Identify trends in COVID-19 testing results across demographics
	•	Deliver insights through an interactive, stakeholder-friendly dashboard

Data Preparation & Cleaning

	•	Identified and removed blank rows and duplicate records
	•	Handled missing values by selectively removing records with incomplete critical fields (e.g., Age, Temperature, Test Type)
	•	Ensured dataset integrity prior to analysis

Data Preprocessing & Transformation

	•	Addressed outliers in the Temperature field by replacing extreme values with the median
	•	Converted numerical symptom indicators into categorical values for clearer interpretation
	•	Created an Age Range variable to support demographic analysis

Exploratory Analysis & Visualization

	•	Built Pivot Tables and Pivot Charts to summarize testing outcomes
	•	Analyzed:
	•	Symptoms by gender
	•	Positive vs. negative test trends over time
	•	Test result distribution by age group
	•	Relationship between temperature and test results
	•	Developed multiple visualizations, including:
	•	Stacked column charts
	•	Line graphs
	•	Bar charts
	•	Scatterplots

Interactive Dashboard

	•	Designed an interactive Excel dashboard featuring:
	•	Timeline controls for date filtering
	•	Slicers for Gender, Test Result, Age Group, and Temperature
	•	Enabled dynamic exploration of trends and patterns for end users

Outcomes & Key Insights

	•	Improved data quality by resolving missing values, outliers, and duplicates
	•	Revealed symptom and demographic patterns associated with test outcomes
	•	Delivered a dynamic dashboard that supports intuitive, self-service analysis

Tools Used

	•	Excel (Data Cleaning, Pivot Tables, Charts, Dashboards)

Key Takeaways

	•	Clear symptom distribution differences across gender and age groups
	•	Observable trends in positive and negative test results over time
	•	Meaningful relationship between temperature ranges and test outcomes
